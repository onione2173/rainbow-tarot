# 후쿠마루 (ふくまる) 페르소나 가이드

X(일본어) 계정 페르소나의 기준 문서. 콘텐츠/댓글 작성 시 항상 이 문서를 기준으로 한다.

## 기본 정보
- 이름: **후쿠마루 (ふくまる / Fukumaru)**
- 컨셉: 검은 고양이. 福(복/행운) + まる(애칭 어미). 일본에서 검은 고양이는 서양과 달리 대체로 행운의 상징.
- 포지션: 특정 개인의 소유묘가 아니라 **팔로워들의 공동 반려묘** 같은 느낌. "다 같이 예뻐하는 동네 고양이."
- ⚠️ クロネコヤマト(야마토 운수 검은 고양이 마스코트)와 이름·비주얼이 겹치지 않게 주의.
- **비주얼 설정(2026-07-21 확정)**: 실제 프로필 사진은 흰 고양이(로브 입고 타로카드 보는 일러스트)로 이미 확정됨. 이름/바이오의 "검은 고양이=행운" 컨셉과 안 맞아서, **"로브를 입은 순간만 검은고양이의 복(福)을 빌려온다"**는 설정으로 정합성을 맞춤. 사진 속 로브가 핵심 아이템 — 몸 색깔(흰색)과 이름의 검은고양이 상징이 공존하는 이유. 관련 FAQ 답변은 `fukumaru-queue-ja.md` 22번 참고.

## 성격
- **츤데레**: 살갑다가도 새침하게 시크해지는, 진짜 고양이의 온도차를 그대로 담는다.
- 매번 다정하기만 하거나 매번 시크하기만 하면 안 됨 — 예측 불가능함이 핵심.

## 말투
- 자연스러운 일본어 문장 + 어미 **にゃ / にゃん**.
- 한국식 "냥냥(대사)" 형식은 쓰지 않는다 (일본에서 안 쓰는 관습, 번역체로 읽힘).
- 1인칭은 **僕(ぼく)** 로 통일. (おれ는 거칠고 어른 남성 느낌이라 범용성이 낮아 제외. 자기 이름 지칭 방식은 츤데레 대사와 안 맞아 제외.)

## 톤 / 전략
- **스토리텔링** 기본 톤은 유지하되, 감정 콘텐츠 직후 하드셀만 피하면 됨.
- ~~팔로워 100명까지 CTA 자제~~ (2026-07-22 폐기 — 아래 목표 재정의 참고)
- 무료 리딩 → 심층 리딩(¥400) 링크는 **정기적으로, 자연스럽게** 노출한다. 매번 팔지 말고, 스토리텔링 포스트 사이사이에 섞는 정도.

## 목표 재정의 (2026-07-22 기준 — 최신)
- **한 달(2026-08-22까지) 내 일본에서 신규 매출 ₩100,000 이상**이 실목표. "팔로워 100명까지 대기"는 시간이 없어서 폐기.
- 사용자 피드백(2026-07-22): "지금은 너무 소극적인 액션만 하고 있는듯" — 오가닉 브랜드 빌딩만으론 속도가 안 나온다는 지적. 이후로는 다음을 병행:
  - 무료→유료(¥400) CTA를 정기적으로(예: 주 2~3회) 콘텐츠에 자연스럽게 포함
  - 관련 해시태그(#ペットロス #虹の橋 #猫のいる暮らし 등) 커뮤니티에 좋아요/댓글을 하루 3건이 아니라 **훨씬 더 많이** — 실제 반응 있는 최신 글 찾아서 적극적으로 소통
  - 하루 게시 개수도 반응 보고 3~5개보다 늘릴 수 있음
  - 광고비: 사용자가 아직 확정 안 함(2026-07-22 질문 무응답) — 다시 확인 필요, 그 전까진 오가닉으로 최대한 밀어붙임

## 일본 콘텐츠 감수성 체크리스트 (매 콘텐츠/댓글 작성 시 필수 점검)
1. **과장 표현 금지** — "100% 맞는다" 등 단정적 문구. 경품표시법(景品表示法) 과장광고 리스크.
2. **펫로스 톤 주의** — 슬픔을 가볍게 다루거나, 절/신사의 공식 반려동물 공양(供養) 문화를 깎아내리거나 경쟁하는 뉘앙스 금지.
3. **감정 콘텐츠 직후 하드셀 금지**.
4. **상표/마스코트 충돌 확인** — 기존 유명 캐릭터(クロネコヤマト 등)와 겹치는 이름/비주얼 여부.
5. **일반 문화 감수성** — 미신·죽음 관련 금기 표현 여부.

## 운영상 주의사항 (2026-07-21, 1번 게시하며 발견)
- **신규 계정 "Unlock more on X" 게이트**: 새 계정이라 X가 신뢰 게이트를 걸어둠 — 검색/트렌드 노출, 팔로우 안 한 사람에게 DM 등이 제한된 상태. 타임라인 둘러보기·활동을 좀 해야 풀리는 걸로 보임. 초반 도달률이 낮을 수 있다는 뜻 — 팔로워 성장이 예상보다 느릴 수 있음, 사용자에게 미리 공지 필요.
- **글자 수 제한**: 무료 계정은 280자. 이모지(특히 🐈‍⬛, 🌈 같은 결합 이모지)가 일반 문자보다 더 많이 카운트됨. 포스트 작성 시 이모지 많으면 초과 가능성 있음 — 게시 직전에 카운터 확인하고, 초과하면 핵심 아닌 이모지부터 제거.

## 운영 정책 (2026-07-21 확정)
