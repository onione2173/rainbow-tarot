사용자가 이모지·따옴표 스타일도 지적했다. 답글 쓸 때 AI처럼 보이면 안 된다고. 맞는 말이라 메모리에 저장했다(가오모지 규칙에 이어 두 번째 톤 규칙).

X API 앱 셋업했다. 앱 권한을 읽기 전용에서 읽기+쓰기로 바꿨다. 순서가 중요했다 — 권한 저장 전에 발급된 토큰은 무효였다. 콘슈머 키도 마지막 6자리만 보여줘서 재생성해서 새로 받았다. 재생성 순서가 뒤바뀌어서(액세스 토큰을 먼저, 컨슈머 키를 나중에 재생성) 한 번 더 액세스 토큰을 재생성했다. 최종적으로 GET /2/users/me 호출해서 200 확인했다. 4개 키 전부 GitHub Secrets에 저장 완료.

push가 막혔다 — 워크플로 파일을 포함한 push는 `workflow` 스코프가 필요한데 없었다. 사용자한테 device code 인증 받아서 스코프 추가했다. `gh auth setup-git`도 다시 돌려야 했다 — scope 추가만으론 git이 바로 새 토큰을 안 썼다.

dev→main 머지, push 완료. 워크플로 수동 실행해서 실제로 확인했다 — 새벽 3시라 "아직 게시 시각 아님"으로 정확히 스킵하고, 오늘자 랜덤 시각(10:12/13:57/18:43)을 새로 뽑아서 상태 파일을 커밋까지 했다. 세션 없이 진짜 돌아가는 거 확인했다.

Pay Per Use 요금제였다. 잔액 $0, 결제수단 없음, 지출한도 무제한으로 설정돼 있었다. 지금은 카드가 없어서 못 나가는 구조다. 소액 한도 설정을 제안했는데 사용자가 지금은 하지 말라고 했다.

사용자가 알림 문제(세션 없을 때 먼저 연락 못 받는 것)를 지적했다. 맞는 말이다. Remote Control 연결하면 최소한 세션 중엔 폰으로 감. 세션 없을 때 알림은 네오라 텔레그램 봇 재사용 제안했는데, 사용자가 이건 별도 "workflow" 프로젝트로 직접 해결하겠다고 했다.

목표가 다시 바뀌었다 — "한 달 내 일본 매출 10만원"으로. 사용자가 "너무 소극적인 액션만 하고 있는듯"이라고 직접 지적했다. 맞말이었다. 페르소나 가이드에서 "팔로워 100명까지 CTA 자제" 규칙을 폐기하고 정기적 CTA 노출로 바꿨다. 광고비 승인 여부는 물어봤는데 응답 없어서, 일단 오가닉 소통량부터 크게 늘렸다 — 라이브 해시태그 검색으로 신선한 글 찾아서 팔로우+좋아요를 이번 라운드에 4개 계정 추가로 진행(#猫のいる暮らし #うちの子自慢 #猫好きさんと繋がりたい). @nekoyomi_yamaz라는 곳은 우리랑 거의 똑같은 컨셉(고양이 페르소나로 반려동물 마음 타로/점) 서비스를 코코나라에서 팔고 있었다 — 직접 경쟁군 참고할 만하다.
